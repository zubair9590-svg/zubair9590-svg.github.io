## ✨ Highlights

- **Hand-built**: plain HTML, CSS and JavaScript, with no framework and no build step
- **Re-themeable**: click a color in the hero palette to change the site's accent color (it's remembered on your next visit)
- **Light and dark themes** that follow your system setting, with a manual toggle
- **Responsive and accessible**: semantic HTML, keyboard-friendly navigation, visible focus states and a skip link
- **Motion with care**: scroll animations are disabled when you prefer reduced motion
- **Fast**: a single small stylesheet and script, and lazy-loaded images

## 🚀 Run it locally

```bash
git clone https://github.com/zubair9590-svg/zubair9590-svg.github.io.git
cd zubair9590-svg.github.io
npx serve .        # or: python -m http.server
```
