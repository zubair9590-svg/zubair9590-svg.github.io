About me

Design eye, developer hands.

I'm Zubair. I enjoy working on both sides of a product: shaping how it looks and feels, then writing the code that makes it real.

My work usually starts in Figma with layout, type, color and contrast, and ends as a responsive, accessible app. Along the way I care about the details: clear interfaces, readable code and tests that keep everything working.

How I work

  1. 01

    Understand

    Start with the problem and the people who have it, and agree on what "done" looks like.

  2. 02

    Design

    Sketch the flows and build the interface in Figma, checking layout, color and contrast early.

  3. 03

    Build

    Turn the design into clean, responsive code with React, Node.js or Python, whichever fits the job.

  4. 04

    Ship & improve

    Test, document and deploy with CI, then keep polishing based on feedback.
